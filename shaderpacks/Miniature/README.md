# Miniature Shader

Bundled, unmodified, from
[minecraft-miniature-shader](https://github.com/mateuskreuch/minecraft-miniature-shader),
Copyright (c) 2022 Mateus A. Kreuch, under the MIT License in `LICENSE`.

The game runs it through Horizon's shader-pack translator. It is the default
look because it is the reference itself, not an approximation. The Rust visual
profile in `crates/horizon-client-render/src/visual/` is the fallback used when
this folder is missing.
